# Character Settings
Save character specific settings, to match when on a different account/profile.

Settings include, but may not be limited to:

* Fkeys
* Spellbook
* Rune Pouch
* Quick Prayers
* Accept Aid
* Auto Retaliate
* Player/NPC attack options priority (i.e hidden/left click etc)
* Game Client (Fixed/Modern/Classic)
* Bank Locks
* Mute status of the various volume channels

Configs allow you to configure what settings you wish to show on the overlay if you choose to omit some.
